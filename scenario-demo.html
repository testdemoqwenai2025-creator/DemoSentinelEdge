Hub exclusive · FAQ

Frequently asked about the demos

Are the sensors in these demos real?→
No — they are synthetic streams generated in your browser by deterministic noise + fault injection. The waveforms, sample rates, alarm thresholds, and fault modes are calibrated to match real deployments (e.g. offshore vibration spectra from ISO 10816). The MVP dashboard at preview space-z.ai uses the same generator. The 1M-row synthetic dataset on GitHub is the training source for the TS-FM.
Can I add my own scenario?→
Yes — design partners get a sector config file (see sectors/ in the platform repo) and a tenant dashboard at /tenant-dashboard. The free tier supports 250 sensors; paid tiers support 50K+. Start at /portal.
Why 7 scenarios, not 12?→
These 7 cover the full range of the 9 hardness dimensions. Verticals we deliberately don't pursue (consumer wearables, smart home, retail) are listed on /what-we-dont-do. We will add 2 more (pipeline + compressor station) once design-partner #3 signs — see next-sprints.md.
How does the edge actually work in these demos?→
Each scenario page simulates the 4-layer architecture (Sensing → Connectivity → Edge Compute → Intelligence) in JS. The "Edge" panel on each page shows the simulated Hailo-8 / Orin placement, KubeEdge node state, and round-trip latency. For the real edge code, see AISensorEdgeComp-Platform.
What's the difference between this hub and sectors.html?→
sectors.html is the configuration view — side-by-side configs for each vertical, suitable for engineering buyers. This page (scenario-demo.html) is the live-demo view — interactive deployments you can click into, suitable for executives and investors. Both link to each other.
