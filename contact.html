FAQ

Common questions

How is your TS-FM different from Chronos or TimeGPT?

Same transformer family. Three deltas: (1) trained on industrial-only data (no general web time-series), (2) sensor-fusion attention layers that operate on multi-modal windows, (3) causal-aware loss function that penalizes correlations without causal backing. The combination gives us +0.07 AUC-ROC zero-shot on industrial benchmarks. See the Layer 04 deep dive for full architecture.

Can we deploy on-prem?

Yes — the full stack (edge + cloud control plane + TS-FM) runs on a single k8s cluster. Air-gapped deployments supported for sensitive verticals (defense, energy, healthcare). Hybrid (on-prem edge + cloud reasoning) is the default.

What's your customer data isolation story?

Per-customer K8s namespace + per-customer encryption keys + per-customer S3 prefix. Federated learning is the only cross-customer data flow, and it shares gradients only — never raw data. SOC 2 Type II audit in flight for Q1 2027.

How do you handle a customer with no labeled failures?

This is the entire point of the zero-shot capability. The TS-FM is pretrained to detect distributional anomalies; labeled failures only improve precision (10-shot raises AUC from 0.89 to 0.93). We recommend customers start with zero-shot, then add labels as they accumulate them.

What's your moat against AWS IoT or Azure IoT?

Horizontal platforms sell plumbing. We sell the intelligence layer — the TS-FM and Graph RAG are not features AWS IoT or Azure IoT offer. We integrate with them (customers can use S3, IoT Hub, etc. as ingest), but the reasoning layer is ours.

How do we evaluate?

Design-partner program: 60-day evaluation, free, with engineering support. See Design partners section above.
