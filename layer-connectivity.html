WAN transport

Any WAN. Anywhere.

Once the gateway has normalized raw bytes into the canonical measurement schema, the data is transported over whatever WAN the deployment uses. The platform is WAN-agnostic — we ride on customer-existing networks rather than competing with telcos.

Semantic normalization

Raw bytes → semantic meaning.

A four-stage pipeline runs at every edge gateway. The first two stages are deterministic protocol decoders (one per protocol). The third stage is where we innovate — LLM-assisted ontology mapping. The fourth stage produces the canonical record.

Semantic Normalization Pipeline

→
Canonical measurement

Edge AI / Cloud stream

The first stage handles the wire protocol — TCP framing, OPC-UA binary encoding, Modbus register layout, MQTT packet structure. The second stage produces a typed record with the protocol-specific tags (e.g., ns=2;s=Line3.CompressorA.OutletPressure for OPC-UA, register 40001 for Modbus). The third stage is where the LLM proposes a canonical mapping — turning ns=2;s=Line3.CompressorA.OutletPressure into physical_quantity="compressor_outlet_pressure", unit="Pa" with a confidence score. The fourth stage emits the final canonical record.

LLM-assisted mapping

The frontier: llm-mapping-example.json

{
  "source_tag": "ns=2;s=Line3.CompressorA.OutletPressure",
  "source_metadata": {
    "description": "Outlet pressure of Compressor A on Line 3",
    "data_type": "Double",
    "engineering_unit": "Pa",
    "eu_range": { "low": 0, "high": 300000 }
  },
  "proposed_mapping": {
    "sensor_kind": "pressure",
    "physical_quantity": "compressor_outlet_pressure",
    "unit": "Pa",
    "sample_rate_hz": 1.0
  },
  "confidence": 0.96,
  "alternatives_considered": [
    { "physical_quantity": "pipe_pressure", "confidence": 0.32 }
  ],
  "requires_human_approval": true
}

Engineers approve; the LLM learns from corrections. Time-to-onboard a new factory drops from 6 months to ~3 weeks. The LLM never writes to the live tag mapping without human approval. All proposals are logged with full provenance for audit (SOC 2 evidence package included).

Engineering note

The LLM is fine-tuned on a corpus of OPC-UA information models, Modbus register conventions, and 200+ customer tag mappings (anonymized). It runs on the customer's own infrastructure — no raw tag metadata leaves the customer boundary. Federated learning only.
