Sensor Types & Higher-Level Architecture

The complete sensor taxonomy and end-to-end architecture for AISensorEdgeComp. 12 sensor types covering every industrial measurement modality — from pressure transmitters to corrosion probes — streaming through a 6-layer pipeline: field instruments → edge gateways → ingestion → Kafka + Flink + Spark Streaming → plant cloud / on-premise big data platform → consumer applications. All readings are synthetic placeholders, streaming live for demonstration.

Worked Example

One vibration event, end to end.

Follow a single anomalous vibration reading from a compressor bearing — through every layer of the architecture — to a CEO's daily brief.

Vibration Event → Executive Brief (Full Pipeline)
L0: IEPE accelerometer detects 11.2 mm/s RMS on compressor bearing (10 kHz raw)
↓
L1: Hailo-8 edge gateway computes features, detects anomaly (RMS > threshold)
↓
L2: Edge publishes via MQTT to ingest service (QoS 1, retained)
↓
L3: Kafka topic telemetry.raw → Flink 30s window → TS-FM inference (confidence 0.91)
↓
L3: Anomaly token emitted to alerts.processed (99.7% bandwidth reduction)
↓
L4: TimescaleDB stores event; Iceberg archives to S3; ClickHouse rolls up hourly
↓
L4: Graph RAG traverses asset graph (compressor → line → maintenance log → ERP)
↓
L5: LLM composes brief with citations; alert routed to plant manager + ops VP
↓
L5: Daily brief auto-generated at 06:00, pushed to CEO dashboard

Total end-to-end latency: < 5 seconds from sensor reading to alert. Daily brief generated at 06:00 local time with full evidence chain.
