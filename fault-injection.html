What you're watching

The platform pipeline, end to end.

Every fault you inject above runs through the same 6-stage pipeline that runs on every design-partner deployment. Here's what's happening at each stage:

Stage 1-2: Edge detection + TS-FM inference

The Hailo-8 edge gateway (2.5W, 26 TOPS) computes features on the raw sensor stream every second. When a feature crosses a threshold, it triggers TS-FM inference on a 30-second window. The TS-FM (350M params, pretrained on 50M hours of industrial data) outputs an anomaly confidence in [0,1]. When confidence > 0.85, an anomaly token is emitted.

Stage 3-4: Kafka + Graph RAG

The anomaly token is published to the alerts.processed Kafka topic (99.7% bandwidth reduction vs. streaming raw data). The Graph RAG layer consumes the token and traverses the asset knowledge graph — sensor → asset → maintenance log → ERP records — gathering evidence to ground the LLM's answer.

Stage 5: LLM composes alert with citations

The LLM (fine-tuned on industrial alerting corpus) composes a natural-language alert using the evidence chain. Every claim in the alert links back to a specific sensor reading, maintenance record, or ERP entry — auditable provenance, not black-box AI.

Stage 6: Alert routing

Alerts are routed by severity: info → dashboard; warning → Slack + email; critical → PagerDuty page + console; emergency → immediate page + PA system + ERP auto-actions (e.g., revoke hot work permits).
