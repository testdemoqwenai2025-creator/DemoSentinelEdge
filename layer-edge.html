Liquid placement scheduler

Not "edge or cloud." "Edge and cloud, fluidly."

Every 30 seconds, the placement scheduler scores each pending inference job across five axes and routes accordingly. The scheduler runs as a control loop on every edge cluster, federated across the customer's fleet. Routing decisions are persisted for audit. Operators can override with hard rules (e.g., "safety-critical inferences always run on-device").

Scoring function

Five axes, placement-score.py (simplified)

# Score = weighted sum of normalized metrics; route to highest-scoring site.
def placement_score(job, site):
    return (
        0.35 * latency_score(job, site)         # end-to-end RTT
      + 0.25 * bandwidth_score(job, site)       # $/GB right now
      + 0.20 * accuracy_score(job, site)       # model drift vs. gold
      + 0.15 * battery_score(job, site)         # device SoC + recharge ETA
      + 0.05 * carbon_score(job, site)         # grid carbon intensity
    )

def route(job, candidate_sites):
    scored = [(placement_score(job, s), s) for s in candidate_sites]
    scored.sort(reverse=True, key=lambda x: x[0])
    return scored[0][1]   # highest-scoring site

The weights are configurable per customer. A utility with substation monitoring might weight latency at 0.60 (safety-critical). An agri co-op might weight bandwidth at 0.45 (cellular is expensive). The scheduler supports hard overrides — "always on-device for safety-critical" — that bypass the scoring function entirely.

Edge autonomy

72 hours without WAN. No degradation.

Every edge cluster runs for 72 hours without WAN connectivity. If your plant loses internet, your TS-FM still flags anomalies, your operator still gets alerts, your maintenance log still records. The cloud is a co-processor, not a dependency.

How: each edge cluster has 72 hours of local buffer for sensor data, a local copy of the TS-FM weights, a local Graph RAG index (synced from cloud every 4 hours), and a fallback LLM (smaller, distilled, runs on Jetson class silicon). When WAN returns, the cluster resyncs the cloud with all locally-recorded events.

Why this matters

Industrial buyers will not deploy AI that breaks when the network does. Edge autonomy is the difference between "AI for the office" and "AI for the plant floor." It's also why we win against cloud-only platforms (AWS IoT, Azure IoT) in industrial.
