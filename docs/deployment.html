Production (Kubernetes + Helm)

# Deploy to production namespace
helm upgrade --install aisensoredgecomp ./helm/aisensoredgecomp \
  --values ./helm/values-production.yaml \
  --namespace production \
  --create-namespace \
  --wait

Air-gapped deployment

For sensitive verticals (defense, energy, healthcare), the full stack runs on a single k8s cluster with no external network calls. Images are pulled from an internal registry; S3 is replaced with MinIO (on-prem).

helm upgrade --install aisensoredgecomp ./helm/aisensoredgecomp \
  --values ./helm/values-airgapped.yaml \
  --set global.imageRegistry=registry.internal \
  --set global.airgapped=true
