Deployment

Local, staging, production, air-gapped

Local development

make up
make health

Production (Kubernetes + Helm)

helm upgrade --install aisensoredgecomp ./helm/aisensoredgecomp \
  --values ./helm/values-production.yaml \
  --namespace production --create-namespace --wait

Production sizing

ComponentReplicasCPU/Mem
Kafka5 brokers4 CPU / 16Gi
Flink TM82 CPU / 4Gi
TimescaleDB3 (HA)4 CPU / 8Gi
ClickHouse3 (sharded)8 CPU / 16Gi

Total: ~120 vCPU, ~256 GiB RAM, ~10 TiB storage.

Air-gapped deployment

helm upgrade --install aisensoredgecomp ./helm/aisensoredgecomp \
  --values ./helm/values-airgapped.yaml \
  --set global.imageRegistry=registry.internal \
  --set global.airgapped=true
