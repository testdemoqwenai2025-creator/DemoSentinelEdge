API Reference

Interactive API explorer

The full API is documented as an interactive Swagger UI on the main site. Below is a summary of every endpoint.

Authentication

All write endpoints require a JWT bearer token obtained via POST /api/v1/auth/login. Tokens are valid for 24 hours.

# Get a token
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"you@company.com","password":"your-password"}'

Endpoints

MethodPathDescription
GET/healthService health (no auth)
POST/api/v1/auth/loginGet JWT token
GET/api/v1/sensorsList sensors

GET/api/v1/sensors/{id}/statsGet aggregated stats

GET/api/v1/maintenanceList maintenance events

POST/api/v1/ml/infer/rulPredict remaining useful life
