Quickstart

Prerequisites

  • Docker 24+ and Docker Compose v2
  • Python 3.12+ (for SDK and scripts)
  • Git
  • 4 GB RAM, 10 GB disk

Step 1 — Clone the repo

git clone https://github.com/testdemoqwenai2025-creator/AISensorEdgeComp-Platform.git
cd AISensorEdgeComp-Platform
cp .env.example .env

Step 2 — Start the stack

make up

This starts: MQTT broker (Mosquitto), Kafka (3.7 KRaft), Schema Registry, TimescaleDB, Iceberg REST, MinIO (S3), ClickHouse, Flink, ingest service, API server, ML inference service, Prometheus, Grafana.

Step 3 — Verify health

make health

Expected output: all services showing ✓ OK.

Step 4 — Send test telemetry

make test-telemetry

Sends a synthetic vibration reading via MQTT. Watch it flow through ingest → Kafka → Flink → TimescaleDB.

Step 5 — Query the API

curl http://localhost:8000/api/v1/sensors | jq

Returns the sensor registry with current state per sensor.
