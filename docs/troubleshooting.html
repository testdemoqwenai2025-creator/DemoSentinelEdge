Troubleshooting

Common issues

Docker Compose won't start

# Check port conflicts
docker compose ps
# Check logs
docker compose logs ingest
# Reset everything
make clean && make up

Kafka connection refused

Kafka takes 10-15 seconds to start. Wait and retry:

sleep 15 && curl http://localhost:8081/subjects

API returns 401

Your JWT may have expired. Re-authenticate:

curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"you@company.com","password":"your-password"}'

ML inference returns 0.0 confidence

The ONNX model may not be loaded. Check:

curl http://localhost:8002/health

If the ML service is healthy but confidence is 0, your input window may be empty or all-zeros. Provide at least 8 samples.

FAQ

Can I deploy on-prem?

Yes — the full stack runs on a single k8s cluster. See the deployment guide for air-gapped instructions.

Do you support my sensor protocol?

We support OPC-UA, Modbus, MQTT, CoAP, Profinet, EtherCAT, LoRaWAN, NB-IoT. See the sensor types page for the full list.

Email platform@aisensoredgecomp.ai. Response within 24 hours. Design partners get a Slack channel with the founding team.
