Data Schemas

Overview

The platform uses Avro for Kafka wire format (with Schema Registry) and Protobuf for gRPC services + storage. Both express the same logical contracts.

Schemas

SchemaAvro (.avsc)Protobuf (.proto)Used by
Telemetrytelemetry.avsctelemetry.protoIngest → Kafka, all downstream
Alertalert.avscalert.protoFlink → alerts topic
Assetasset.avscasset.protoAsset graph, Graph RAG
Maintenancemaintenance.avscmaintenance.protoMaintenance log, ERP

Full schema files are in the platform repo.

Versioning

All schemas use the com.aisensoredgecomp.v1 namespace. Breaking changes require v2. Backward-compatible changes (add optional field, add enum value) are in-place. Schema Registry enforces BACKWARD compatibility.

Code generation

# Avro → Python
pip install avro
python -c "import avro; avro.schema.parse(open('schemas/avro/telemetry.avsc').read())"

# Protobuf → Python
pip install grpcio-tools
python -m grpc_tools.protoc -I schemas/proto \
  --python_out=./generated --grpc_python_out=./generated \
  schemas/proto/*.proto
